   explicit Dismiss.

   on open; a terminal-held session stays read-only with an explicit Take over (recommended).

   toggles: defaults for new MAWS sessions only, or shared Claude Code settings.
6. Resume scope: current project with All projects one click away (recommended) or all folders first.
