2.5 Why /reload-plugins is grey, and what is automatic

M/src/renderer/src/composer/mentions/items.ts:68–79 dispatches a registered widget first, otherwise inserts headless commands, otherwise disables terminal-only commands. /reload-plugins is in the engine’s terminal_slash_commands, and no widget/action with that name is registered (widgets/index.ts:28–50). Hence “Terminal only.” This describes the terminal slash implementation, NOT the ability of MAWS to reload via control. /reload-plugin singular is not the advertised engine name.

Current manual alternatives exist: “Reload mods” and “Reload skills” in /plugins and panel Summary; Reload in /skills. M/src/renderer/src/widgets/plugins/reload.tsx:35–54 calls session.reloadPlugins and session.reloadSkills, and updates operation status. The host publishes reload data immediately into loaded state/catalogue (M/src/engine-host/session-status.ts:123 onward; session.ts:483 onward).

Current automatic behavior is narrow and explicit: after a successful MAWS-initiated install/update/uninstall/enable/disable/marketplace-update/marketplace-remove, runner invokes reloadAfter; marketplace-add alone does not reload. It waits 3 seconds, reloads every ready MAWS session, verifies presence/absence/version only for applicable scope, retries a disagreement once after another settle, and reports reflected/not_reflected/failed independently from CLI success (M/src/engine-host/plugins/runner.ts:266–290; plugins/reload-after.ts:15–18, 40–73). There is no general automatic MAWS reload proven for arbitrary external terminal/file edits. The probe showed a settings edit + next turn alone did not apply the disabled plugin. Therefore retain an explicit Reload plugins action and make the palette name route to it, with honest busy/not-running feedback; do not imply universal background hot reload.

Install/update/uninstall/enable/disable: existing engine CLI commands with user/project/local scope after current confirmation sheet; no terminal needed; MAWS has no need to write settings itself.
Add/refresh/remove marketplace: existing engine CLI through current confirmations; remove may uninstall plugins. No terminal needed.
