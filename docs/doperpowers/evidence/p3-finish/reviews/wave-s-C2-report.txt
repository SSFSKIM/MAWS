**Your slug question (F11)**
A deck's `<slug>/` and a document's `<slug>/assets/` meet only if both slugs are equal. `mirrorSlug` is the sanitized title plus the first 8 hex characters of a random UUID, so it takes the same title and the same 32-bit id prefix: 1 in 2^32 per same-titled pair. Even then, the only shared path is `<slug>/assets/<name>` with the same asset name. The manifest's ownership rule refuses the second artifact's write of a file another entry owns ("is not the mirror's file; not written", logged), and removal only prunes empty folders. So neither can overwrite or delete the other's files; at worst one image is missing. Two decks with one slug behave the same way today, so this is the existing guarantee, not a new gap.
