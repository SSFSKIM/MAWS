## Decisions

- The tool is the one `maws` tool listed with `_meta["anthropic/alwaysLoad"]`: tool search must never defer the channel to the owner.
- The launch allows the tool, since default mode otherwise asks a permission for each call and a message must never wait on one.
- A call whose result has not arrived in an open turn draws as a message; a refused, blank or unanswered-at-close call is the engine's cell and counts as a tool call.
- A message row stays in view when its turn folds, on any lane.
- Contract 7 is contract 5 plus one rule paragraph, the rest byte-identical, so a recorded snapshot reads as before.

## Surprises

- The engine itself asks for thinking display `updates` on every main request (beta `thinking-display-updates-2026-08-18`), so MAWS's wire carries the paraphrase rather than an empty block.
- A note the prompt asks for stays text; the loss comes in the model's own words between pieces of work, which is where a request to act tends to sit.
- MAWS's own lane-on sessions on 2.1.303 held no visible note in 220 responses with a tool call, 149 opening with an empty thinking block: their loss was silent.
- The ClaudeUsage relay answers 429 to a bare Messages request and serves one shaped as Claude Code's (logged in the Friction tracker, MAWS #92).
