## Decisions

- A plugin call in a MAWS reader counts as work like any MCP call, and a pending one draws as a running cell.
- `messageTools` is optional on the source and defaults to MAWS's own tool, so no MAWS caller changes; the state keeps the list for its life and takes it again from the source on every attach, staged restart, retry and reset.
- `contract.test.ts` keeps the plugin's name as a local literal, since supplement 2 still names it as not available here.
