- The to-human mod draws in MAWS: the owner changes the mod (doperpowers PR 363), MAWS keeps `MAWS_NATIVE_TO_HUMAN` for the message tool; MAWS's surface gained Button children and hover, keyed Box hover and the theme's claude colour, verified against a no-inference 2.1.309 render fixture.

- The report bar offers Mark read from one item and clears legacy essential and question items, so nothing sticks in Needs you after the cards went.
- Tool rows take the Bash description or the tool's name; the engine's summary generation stays off (Claude Desktop's Code sets it false) and a summary that arrives is attached by its preceding tool-use ids.
- Project membership: explicit adds and MAWS launch or resume evidence persist; live, waiting or pinned CLI work keeps a project only while it lasts; an explicit removal wins.
- Automatic archive defaults to Never and skips open tabs; an explicit archive closes its tabs.
- Shift-command T stays one reopen over tabs and sessions together. Sessions keep the shift-command bracket chords (the owner's answer).
- Settings fields were added defaulted on each branch and versioned once, v18, at integration.

- Typed text matching the engine's interrupt marker was stamped as an interruption, at backfill and again on the live echo, before the new turn closing made it visible; both fixed with regressions.
- Claude Desktop's tool-row labels come from the agents' descriptions, not generated summaries; a headless engine emits a summary after the final answer when the switch is on.
- Playwright cannot fire a native menu accelerator, so a keyboard-shortcut acceptance goes through the menu item.
