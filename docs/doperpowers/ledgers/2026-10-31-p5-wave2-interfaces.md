# P5 wave 2: the interface ledger for O4, O5, O7 and O16 (2026-10-31)

> **Parent:** `docs/doperpowers/plans/2026-10-27-p5-org.md` (P5), children O4, O5, O7 and O16, whose execution documents are `docs/doperpowers/plans/2026-10-31-p5-o4-services.md`, `2026-10-31-p5-o5-chromium.md`, `2026-10-28-p5-o7-remote-lane-b.md` (re-planned) and `2026-10-31-p5-o16-holder.md`. **Writer:** the MAWS architect; executors send changes to the architect and do not edit this file. **Why it exists:** the four children build at the same time and each extends contracts the others touch (decomposing's interface ledger); this is the one interim contract they code against, reconciled before the first executor starts and kept current as they land.

## Rules that bind all four

1. **`WIRE_MINOR` is taken at landing, never reserved.** Every document names "13" as its next minor because all four were planned against master at 12. None owns 13. Each landing re-reads `src/shared/ipc/wire.ts` on its merge with master, takes master's minor plus one, regenerates `wire-manifest.json`, and keeps the change additive (OX1). A milestone that does not change the wire (O7's M2) takes none. An overtaken branch re-bumps when it merges master, and its cross-build run pairs with a master commit one minor back (`--peer`, ci-gate's PEER_E2E rule since #388).
2. **One landing at a time on master**, through the architect, in arrival order unless a row below says otherwise. A landing merges current master first; the later lander reconciles a shared file, never the earlier one.
3. **The idle headroom is shared.** `e2e:daemon-idle` reads a median 91,235 KiB against 99,145 on the mini (7,910 KiB of headroom). Each child expects to add nothing at `mawsd`'s idle (O4: its services load with the spine; O5: the render host starts on demand and exits; O16: its new engine-host code must fit, and each session host is read by its own measured bound). Every landing that touches `mawsd`'s eager graph or the engine host runs the series on the mini under CI-opt's hold, on the architect's go, against the bound re-derived on its own merge tree; a miss in two of three valid runs stops that landing and goes to the architect as P5's Q2.
4. **New measured groups** enter `MEASURED_E2E` in `.github/workflows/gate.yml` with CI-opt's review at landing: `e2e:daemon-idle-render` (O5), `e2e:daemon-idle-session-host` (O16), `e2e:remote-latency` (O7). Only CI-opt launches measured groups.
5. **A name an executor adds that is not below** (a capability, a command, an event, a shared file) goes to the architect before its milestone lands, so this ledger stays the whole list.
