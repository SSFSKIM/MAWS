The authoritative wave command runs `ci-gate.sh` inside a wrapper that appends one terminal marker whatever way the script ends; `ci-gate.sh` itself is unchanged (gate-owned):

```sh
W=/Users/new/Developer/GitHub/MAWS/.claude/worktrees/agent-af4cd2993bc56e015
log=/tmp/maws-review/gates/p3f-<wave>-ci.log
nohup bash -c '"$@"; echo "p3f-gate-exit: $?"' p3f-gate \
  "$W/scripts/ci-gate.sh" "$W" --class1a pool --runner macos \
  --gates static,unit,probes,unit:darwin,<named-groups> --evidence \
  --label p3f-<wave> > "$log" 2>&1 &
```

Launch in one background shell, then await it in a second with the binding loop, never ad-hoc polling. Shell variables do not persist between tool shells, so the second shell assigns the same log path itself:

```sh
log=/tmp/maws-review/gates/p3f-<wave>-ci.log
until grep -qE '^(ci-gate: run [0-9]+ [a-z_]+|p3f-gate-exit: [0-9]+)$' "$log"; do sleep 30; done
```

The wait ends on whichever comes first: `ci-gate.sh`'s real completion line or the wrapper's marker. Read the result only from the completion line `ci-gate: run <id> <conclusion>`. A marker with no completion line means the script ended before a run conclusion (a usage or alert refusal and other exit 2s, a failed push, no run triggered, a run that could not be read): that is escalated to the architect at once with the log's last lines and any `ci-gate: https://github.com/…/runs/<id>` line, and no pass, fail or skip is written for it. A run that started but was not read is reported by that id as unread, its conclusion taken later from `gh run view <id>` only. The specific group list is one comma-separated value. Under gate-offload DL67, a list naming none of static/unit/probes skips class 1a; include them when shared code changes. Gate run id, source hash, per-group pass/fail/skip counts, evidence location and interpretation are retained under E, not left only in `/tmp`. Group names are those `.github/scripts/gate-plan.mjs` accepts (`e2e:<group>` with a package script); `e2e:artifacts-perf` exists only once W-E lands it.

The hand-back gate is the whole class-1b set with `--evidence --label p3f-final` and **no `--gates`** (ref `ci/p3f-final-<short>`, the reserved final-bundle label), launched on the frozen source after the own-diff review is clean (M4).
