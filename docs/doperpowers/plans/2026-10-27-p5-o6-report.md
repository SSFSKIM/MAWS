## Debt (for `docs/tech-debt-tracker.md`)

- **Numeric `.smns` values.** Python's `str()` keeps some JSON number spellings that JavaScript's does not (`42.0`, `1e3`, `0.000001`, integers above 2^53), so those derive a different key from sminos's. sminos writes string ids. From M5's review. `src/main/index/org-project.ts`.
- **Context-only merges keep insertion order.** A context-only merge with no open set to supply a base keeps insertion order. From M5's review.
- **`store-diagnostics.ts` mixes `session.projects.changed` revisions across machines.** It is a diagnostics harness.
- **TerminalView's `hostReady` reads the local pty host,** even for another machine's terminal.
- **`fs.tasksChanged` keys by listId only.** It has no consumer.
- **Test-builder tidy-ups from M2.** These are the `fakeClient` PreloadBridge casts.
- **FloatingCard's release handler saves the size from the last render.** In `src/renderer/src/shell/FloatingCard.tsx`, if the pointer is released before React renders the moves, nothing is saved and the card snaps back. A happy-dom test with the move and the release in one `act` reproduces it. The fix is to keep the drag's latest size in its ref. People are unlikely to hit it. Found by the panel flake's diagnosis.
- **A just-floated card shrinks its height once,** by about 29 px, after its content shows. This may read as a one-frame jump of its top edge.
- **`panel.<address>` keys of a machine dropped from the roster** are not swept (M4). `settleMachine` sweeps them only for a machine that reports.
