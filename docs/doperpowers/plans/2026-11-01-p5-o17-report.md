## Residue (for tickets)

- **The descendant veto holds real cua sessions.** This is O16's code on master, not O17's. A stdio MCP server is exempt only by argv match against `mcp_status`'s config. After an adoption a bare `node` command is left unmatched (`session.ts:763`, `launcher.ts:277`). Plugin servers in the owner fixture carry no config. So a real session running cua would never be idle-released. Scene 9's idle close and D20's exception pass on the stub's connector until `o16-veto-mcp` lands; the architect has dispatched that fix.
- **Linux pass 3 is manual.** `render-host` is not in `LINUX_E2E`, so pass 3 on Linux is covered only by this VM run. Playwright's `--no-sandbox` default on Linux, now overridden by `chromiumSandbox: true`, shows what an automated Linux lane would have caught. The architect is adding the tracker row.
- **Electron upstream.** An offscreen `window.open` child never gets `SetWebContents`, so it is never sized (v44.4.5 and main 9c80dad42f). The draft issue, with a runnable repro, citations and a suggested fix, is in `task-8-report.md` under "Fix 8". Filing it is the owner's call.
- **`Emulation.setVisibleSize`** is experimental and deprecated in CDP. Every Electron or Chromium bump re-checks it; pass 3's size assertion and the logged CDP error are the tripwire. The architect is adding the tracker row.

- The local stage's e2e was written blind, because Electron e2e is barred on the MacBook, so every scene's first run was on CI. Pass 3 took eight fix rounds, most of them diagnosed from CI logs.
- Local typecheck is barred too. The landing fix wave's type predicate (`idle-release.ts`) reached a full gate before static caught it, and cost a recut. The architect's friction row now says every product commit gets a static-only CI check first.
- `pnpm wire:manifest` refuses an additive change on an unlanded branch. The friction tracker entry `MAWS/live/wire-manifest-regen-refuses-additive-change-on-unlanded-branch.md` gives the workaround: regenerate from master's manifest with a temporary bump.
- The Linux VM needed the Electron binary (`pnpm exec install-electron`), a SUID `chrome-sandbox` (AppArmor restricts unprivileged user namespaces), and Playwright's sandbox option. That is the friction tracker entry `MAWS/live/linux-vm-electron-e2e-needs-binary-suid-and-playwright-adds-no-sandbox.md`.
- A worker's `devcloud vm down` was blocked by the auto-mode classifier as an irreversible deletion. The controller, which created the VM under the brief's rule, took it down.
- The harness forced mid-run hand-backs while workers were still in flight. Each was resumed from the ledger.
