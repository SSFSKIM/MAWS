# U14 · Checks on the owner's machines

> **A child of the UX wave.** Root: `docs/doperpowers/specs/2026-11-12-ux-wave-design.md`. Read it first: it holds the wave's purpose, its laws (law 1 to law 8), the contracts UC-1 to UC-15, the ordering and the record. This file is this child's section of that document. Where this file and a contract's statement in the root differ, the root binds; report the difference. **Grain:** spike (findings, never a merge). Items are named by their ids in the register, `docs/doperpowers/evidence/ux-wave-2026-11/register.md`.

- **Purpose:** some items cannot be settled from the code: the code allows two causes, or the fault was seen once on one machine, or a number was never measured on real machines. Each check here answers one such question on the owner's own machines, so that the child that owns the item builds a fix for the cause that is real and builds nothing where the fault does not reproduce.
- **Acceptance:** every check below has a recorded verdict: what was done, what was seen, and which of its outcomes holds, in `docs/doperpowers/evidence/ux-wave-2026-11/checks.md` (no screenshot of the owner's and no session text; UC-11). Each verdict is carried into the item's section as a dated Decision Log line by the wave's architect.
- **Edges:** blocked-by: external, a sitting of about forty-five minutes with the owner for the checks marked *owner*, and the mini's operator session for those marked *agent*; a check marked *wave build* needs a build that holds the named child's change. blocks: U7 (S-03), U13 (l6-artifacts-13), U3 and U9 (O-33, O-35, O-39), U5 (O-46), U10 (l6-artifacts-09), U11 (#476, S-09), U6 (l5-code-07, O-37), U12 (Stop during a computer-use call).
- **Contracts:** UC-11.
- **Design inheritance:** advisory: run a check on build F unless it says otherwise, so that the verdict is about what the owner uses; where a check needs a log line that F does not write, the owning child adds the line first and the check runs on the wave's build.
- **Required:** required for the items each check gates; the wave can close with a check recorded as "did not reproduce", which moves its item to the tracker with the method kept. **Status:** not dispatched: waiting for a sitting.
