- **Purpose:** beside a session the owner sees what matters about it without opening anything: where it is working and what it changed, and, only while there is any, what it has running, as a tree of its subagents and a list of its background tasks. Finished work no longer takes the top of the two panels; a panel for watching work opens narrow; the Context card loses three buttons that belong elsewhere. And once an agent moves into a worktree, the Environment card, Review, Source control, Files and a new terminal follow it instead of staying on the folder the session was launched in. The tools opened beside the chat are tabs of the side column, one in view at a time; nothing is placed under another by itself, and the owner can stack a second group of tabs under the first.

## O-05 · Two cards for running work; Artifacts leaves; Environment opens

- **Today:** `panel/summary/Summary.tsx` draws four cards in a fixed order, Environment, Context, Connectors, Artifacts, each folded at first and folded again at every change of session (`FloatingCard.tsx` keeps the fold in component state under a key of the session). - **After:** the column is UC-9's. The two new cards:
  - **Subagents.** Heading: "Subagents" and "N running" (every running agent, nested ones included); a click on the heading opens the Subagents panel. Rows: the session's first-level agents, the ones its main loop dispatched, that are running or have a running agent under them, in the order they started, four at most and then "N more", which opens the panel; "N more" counts first-level rows, and the rows opened beneath one do not count toward the four. A card's rows are read from the same list as its panel's, by the same rule. An agent whose own run has ended with only tasks still running is not on the card: its tasks are rows of the Background tasks card, the panel keeps it under Running (#359), and it is on the card again if the engine wakes it. "N running" is the number the panel's "Running N" shows, and no third count is drawn: the tools' own summary lines read the same selectors or are not drawn. An agent whose parent the session does not list is drawn at the first level with today's "· nested" mark.
    - *A row:* the agent's mark; its name; one line of state, which is its current activity ("Reading store.ts"), or "Approval needed" in the warning colour while a request of its own waits, or "Working"; and a coarse elapsed time in minutes that changes on the slow tick, never a seconds counter, drawn only while the row runs and its time is known.
    - *Nested agents.* A row that has agents running under it shows "(+N)" and then a disclosure arrow at the row's right end, before the elapsed time, as the Claude Code CLI writes a dimmed " (+N)" after a row's name in its agent panel. N is the running agents under that row at any depth, agents only: a shell a nested agent started is listed in Background tasks and is not counted here. The row's line of state does not say how much runs under it. "(+N)" with its arrow is a control of its own: a press on it opens or closes what is under the row, drawn beneath it as indented rows with a rule at their left, one level at a time. A press anywhere else on a row opens that agent in the Subagents panel, for every row, whether or not it has agents under it; so a row's press means one thing, a row shows one arrow, and there is no second arrow on hover. An opened row shows its arrow turned and no count. On the card the arrow is drawn only while agents run under the row: an opened row whose last running agent ends loses its arrow and lists nothing beneath it, and its row in the panel stays open; each nested row carries its own "(+N)" when agents run under it, and nothing deeper is listed until that control is pressed.
