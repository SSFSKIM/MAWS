# Word cut: the scenes

> Part of `docs/doperpowers/specs/2026-11-16-word-cut-design.md`. The screens the rig `e2e/words-shots.rig.ts` takes, each from any build on repository fixtures under a scratch profile, so that a before and an after picture differ only in the app's words. The 107 scenes of rounds 1 and 2 are the screens the owner judged at the pin (round 1 on 2026-11-15, round 2 on 2026-11-16); M0 carried them onto master (the UX wave as it left it, `028cecd10`) and added 68 (round `m0`) for states the rounds never reached and for surfaces the wave added. 3 of the old scenes have no target on master. M1 added 48 (round `m1`) for the Settings and Org states its cut draws: rows' notes on pointing and focus, tooltips reached by focus, menus opened, search, the Org for someone who may not sign and for a quiet org, and for each scene with a note open its twin under the note placement prototype (`m1-<scene>-overlay`, `<html data-note-placement="overlay">` set before the note opens). The rig records each scene's meta and whether it was reached in `<WORDS_OUT>/_run.json`.

**Taking the pictures.** On a Mac (the rig opens app windows), from a clean checkout of the build to photograph:

    pnpm install
    WORDS_OUT=$HOME/maws-words/before pnpm shots:words

`pnpm shots:words` builds `out/` and runs the rig's seven launches through `playwright.words.config.ts`, its only selection (the file is not a `*.spec.ts`, so no e2e group and no default run collects it), in about 30 minutes. The pictures are `<WORDS_OUT>/<scene>.png`. `WORDS_ONLY=<id>,<prefix>*` narrows a run to some scenes. The "before" set is this command on master; the "after" set is the same command on a milestone's branch into another folder.
