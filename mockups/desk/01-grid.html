Which project is waiting on you?

Recommendation: B, the tiles. It is the only variant where the answer reads from across the room: a project that needs you carries a large amber numeral on a tinted tile, and every other tile stays quiet, so the signal never competes with itself. A is the better pick if the desk lives in a narrow side pane next to other work; C wins once the org passes about twenty projects, where scanning a column beats scanning tiles. Sort, in all three: waiting (most first), then working (most first), then name; a project with every machine offline sorts last whatever its counts.
