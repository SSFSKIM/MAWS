The desk / Project view / 02 View in dark

One project: its channel, its sessions, and room for depth.

Opened from a grid tile. The sidebar is the project's people: the group channel first, then each session as a direct channel, grouped by what it needs from you. Empty groups are hidden; Ended is collapsed, since it only grows. A session on an offline machine stays in the group of its last known state, dimmed and tagged, so it does not jump around while the machine sleeps. Click # MAWS or a session to see the selected state move.
