The desk / Group chat / 03 View in dark

When sessions talk to each other, the group chat folds it to one row.

Recommendation: A, the ledger line. It puts a run of agent traffic at the weight of a system line: one muted row with how many messages, who was in it and when, which tells you whether to open it without inviting you to read it. The stream stays yours: what sessions sent you and what you posted are the only things that read at full voice. B is the better pick if you find yourself opening most runs to learn what was decided, because it quotes the last word of each run. C wins if runs grow long and you audit them often, since reading one never moves your place in the stream. The trouble with C is that it spends the right column, which is reserved for a session's depth, on traffic.

A run is a stretch of consecutive says between sessions with nothing addressed to you in between; a message to you, a question, a prompt, a system line, or anything a human posts ends it. A run of one message is drawn whole on one line (“1 message between agents” would be a fold with nothing to hide), and it becomes a fold once a second message joins it.
