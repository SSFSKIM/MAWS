# LC-3 손으로 하는 단계 (ChatGPT 앱)

MAWS P4-B3의 LC-3 중 소스 코드로 답이 나오지 않는 부분만 남겼습니다. 나머지(문턱값 320/160, 카드 기본 크기, 바깥 클릭과 Escape, ⌥L, 창 크기 규칙, 118 px 여백, 단축키)는 코드에서 확인했습니다.

**예상 시간: 약 21분.** 단계마다 끝에 무엇을 찍을지와 파일 이름이 있습니다.

## 찍는 방법

- **사진**: ⌘⇧4를 누르고 스페이스를 누른 뒤 ChatGPT 창을 클릭합니다(창 하나만 찍힘).
- **녹화**: ⌘⇧5에서 "전체 화면 기록"을 고르고 "기록"을 누릅니다. 끝낼 때는 메뉴 막대의 ■ 버튼을 누릅니다.
- 기본 위치(데스크탑)에 저장되면 됩니다. 이름은 `lc3-01.png`처럼 바꾸면 좋지만, 바꾸기 번거로우면 **순서대로 찍기만** 해도 됩니다. 찍은 시각 순서로 맞춥니다.
- 픽셀은 사진에서 제가 잽니다. 창 크기는 바꾸지 마세요.

## 준비 (3분)

0. ChatGPT 앱을 열고 메뉴 막대에서 **ChatGPT ▸ ChatGPT 정보**를 엽니다. 버전이 보이는 창을 찍고(→ **사진 `lc3-about.png`**) **확인**으로 닫습니다. 단계를 하는 도중에는 앱을 업데이트하지 마세요(처음부터 끝까지 한 버전으로).
1. 사이드바가 보이면 사이드바가 보이면 **사이드바 숨기기**(⌘⇧S)로 숨깁니다. 끝에 원래대로 돌립니다.
2. `/tmp/lc3-scratch` 폴더를 프로젝트로 열고, 그 안에서 새 로컬 채팅을 시작합니다. 파인더 창에서는 ⌘⇧G를 누르고 `/tmp/lc3-scratch`를 입력하면 됩니다.
3. 입력창 아래의 권한 버튼(툴팁 **권한 변경**)에 지금 무엇이 쓰여 있는지 봅니다. → **사진 `lc3-00.png`**(원래 값 기록용). 그다음 **승인 요청**을 고릅니다.
4. 아래 문장을 붙여 넣고 보냅니다. 답이 끝까지 나올 때까지 기다립니다.

   ```
   1부터 150까지 숫자를 한 줄에 하나씩 써 줘. 도구는 쓰지 마.
   ```

5. 파일 트리(⌘⇧E)에서 `long.md`를 클릭해 채팅 옆에 미리보기 탭으로 엽니다. 채팅이 왼쪽, long.md가 오른쪽에 있으면 됩니다. → **사진 `lc3-01.png`**

## A. 끌어서 띄우기, 왕복 (6분)

6. 채팅 입력창에 `초안 가나다`를 쓰고 **보내지 않습니다**. 채팅 대화를 위로 올려 숫자 **40** 근처가 화면 위쪽에 오게 합니다. → **사진 `lc3-02.png`**
7. 녹화를 시작합니다(⌘⇧5). 채팅과 long.md 사이의 세로 구분선을 **천천히** 왼쪽(채팅 쪽)으로 끕니다.
   - 채팅이 더 줄지 않는 곳에서 2초 멈춥니다.
   - 계속 왼쪽으로 끌어 long.md가 화면 전체로 넓어지면, 버튼을 누른 채 2초 멈춥니다.
   - 누른 채로 오른쪽으로 3 cm쯤 되돌려 채팅이 다시 나타나는지 봅니다. 2초 멈춥니다.
   - 다시 왼쪽 끝까지 끌고 놓습니다. 2초 뒤 녹화를 멈춥니다. → **녹화 `lc3-03.mov`**
8. 놓은 직후의 화면을 그대로 찍습니다(떠 있는 채팅 카드의 모양과 위치, 입력창의 초안). → **사진 `lc3-04.png`**
9. 떠 있는 카드의 입력창 초안 끝에 ` 추가`를 씁니다. 카드가 입력창만 보이는 작은 모양이면 카드를 펼쳐 대화가 보이게 합니다. → **사진 `lc3-05.png`**(초안, 대화가 어느 숫자에 있는지)
10. 카드의 손잡이(툴팁 **드래그하여 이동 · 클릭하여 옵션 보기**)를 클릭합니다. 메뉴가 열린 채로 → **사진 `lc3-06.png`**. 그다음 **왼쪽 창으로 이동**을 누릅니다. → **사진 `lc3-07.png`**(채팅 폭, 초안, 대화 위치)
11. 사이드바를 잠깐 열어(⌘⇧S) 다른 채팅 아무거나 눌렀다가, 다시 LC-3 채팅으로 돌아오고, 사이드바를 다시 숨깁니다. → **사진 `lc3-08.png`**(채팅 폭)
12. ⌘Q로 앱을 끄고 다시 엽니다. LC-3 채팅을 엽니다(사이드바는 숨긴 상태로). → **사진 `lc3-09.png`**(채팅 폭)

## B. 승인 요청이 카드를 여는지 (5분)

13. 구분선을 왼쪽 끝까지 끌어 다시 띄웁니다(녹화 없이). → **사진 `lc3-10.png`**(두 번째로 띄웠을 때의 모양)
14. 카드가 펼쳐져 있으면 long.md 본문을 한 번 클릭합니다. → **사진 `lc3-11.png`**(카드가 작아졌는지). 카드가 작은 모양이 아니면 이 상태로 계속합니다.
15. 카드 입력창에 아래를 붙여 넣고 보냅니다. 승인 카드가 나타날 때까지 기다립니다. → **사진 `lc3-12.png`**(카드가 저절로 펼쳐졌는지)

    ```
    승인 테스트야. ls /tmp/lc3-scratch 명령을 샌드박스 밖 권한(require_escalated)으로 실행하도록 나에게 승인을 요청한 다음 실행해 줘.
    ```

    1분이 지나도 승인 카드가 나오지 않으면 대신 이것을 보냅니다: `curl -sI https://example.com 을 실행해서 첫 줄만 알려 줘.`
16. 승인을 기다리는 동안 카드의 **채팅 최소화**를 누릅니다. 5초 기다립니다. → **사진 `lc3-13.png`**(작은 버튼으로 남아 있는지)
17. 작은 버튼을 눌러 카드를 다시 열고 **한 번만 허용**을 누릅니다. 답이 끝나면 → **사진 `lc3-14.png`**
18. 15번의 문장을 한 번 더 보내고, **곧바로** **채팅 최소화**를 누릅니다(승인 카드가 뜨기 전에). 승인 요청이 오면 → **사진 `lc3-15.png`**(최소화가 저절로 풀렸는지)
19. **한 번만 허용**을 누르고 곧바로 다시 **채팅 최소화**를 누릅니다. 답이 끝날 때까지 기다립니다. → **사진 `lc3-16.png`**(작은 버튼의 표시, 위치. 답 미리보기 카드가 함께 떠 있으면 그대로 찍히게 둡니다)

## C. 위치를 바꾸고 다시 켜기 (3분)

20. 작은 버튼을 눌러 카드를 열고 펼칩니다. 손잡이를 끌어 카드를 화면 **왼쪽 위 1/4 영역의 가운데쯤**에 놓습니다. 가장자리에 너무 붙이지 마세요(가장자리에 붙이면 창으로 붙습니다). → **사진 `lc3-17.png`**
21. ⌘Q로 끄고 다시 열어 LC-3 채팅을 엽니다. → **사진 `lc3-18.png`**(떠 있는지, 펼쳐졌는지, 위치)
22. 카드가 떠 있으면 손잡이를 끌어 **오른쪽 아래 1/4 영역**에 놓습니다(원래 설정이 오른쪽 아래입니다). → **사진 `lc3-19.png`**

## D. 카드와 작은 버튼의 위치 왕복 (3분)

22번에서 카드가 펼쳐진 채 오른쪽 아래에 떠 있는 상태에서 시작합니다. 옮길 때마다 가장자리에 너무 붙이지 말고 각 1/4 영역의 가운데쯤에 놓습니다.

23. 손잡이를 끌어 카드를 **오른쪽 위 1/4 영역**에 놓습니다. → **사진 `lc3-23.png`**(카드가 자리 잡은 곳)
24. **채팅 최소화**를 누릅니다. → **사진 `lc3-24.png`**(작은 버튼이 간 곳)
25. 작은 버튼을 끌어 **왼쪽 아래 1/4 영역**에 놓습니다. → **사진 `lc3-25.png`**(작은 버튼이 자리 잡은 곳)
26. 작은 버튼을 눌러 카드를 다시 엽니다. → **사진 `lc3-26.png`**(카드가 돌아온 곳: 오른쪽 위인지, 다른 곳인지)
27. 다시 **채팅 최소화**를 누릅니다. → **사진 `lc3-27.png`**(작은 버튼이 돌아온 곳: 왼쪽 아래인지, 다른 곳인지)
28. 원래대로 돌립니다. 작은 버튼이 오른쪽 아래가 아니면 끌어서 **오른쪽 아래 1/4 영역**에 놓습니다. 작은 버튼을 눌러 카드를 열고, 카드가 오른쪽 아래가 아니면 손잡이를 끌어 **오른쪽 아래 1/4 영역**에 놓습니다. → **사진 `lc3-28.png`**(카드가 오른쪽 아래에 있는지)

## 되돌리기 (1분)

29. 권한 버튼을 `lc3-00.png`의 원래 값으로 돌립니다. 사이드바를 처음 상태로 돌립니다(처음에 보였다면 ⌘⇧S로 다시 엽니다).
30. 끝났다고 알려 주세요. 사진은 제가 데스크탑에서 읽어 갑니다.

만든 것: `/tmp/lc3-scratch` 프로젝트 하나, 그 안의 LC-3 채팅 하나. 지우지 않아도 되고, 지울지는 정하시면 됩니다.

## (시간이 남으면, 1분) 전체 화면과 단축키

31. 채팅을 **왼쪽 창으로 이동**으로 붙인 뒤, long.md 탭 머리의 **전체 화면으로 확장**을 누릅니다. → **사진 `lc3-20.png`**(채팅이 같은 카드로 뜨는지)
32. ⇧⌘B를 한 번 누릅니다. → **사진 `lc3-21.png`**. ⌥⌘B를 한 번 누릅니다. → **사진 `lc3-22.png`**. 다시 각각 한 번씩 눌러 되돌립니다.
